# 025 — Node 26 for every Node service

## Context

The Node services (`apps/bff`, `apps/web`'s build, `mcp-gateway`, `mcp-accounts`, `mcp-payments`) ran
on Node 22, which has been in maintenance LTS since October 2025 and gave the team trouble.
As of November 2026, Node 26 ("Lithium") is the Active LTS line and Node 24 is in maintenance. Dependencies
in the lockfile already accept 26 (the strictest ranges are `^24.15.0 || >=26.0.0` and `>=22.15.0`).

## Decision

Use Node 26 everywhere: the `node:26-slim` base image in every Node Dockerfile, `node-version: '26'` in CI,
`"engines": { "node": ">=26" }` and `@types/node` 26 at the root. Skip 24, because it is already in
maintenance and would need another bump within a year.

## Consequences

- Contributors need Node 26 locally; the README and `docs/DEMO.md` say so.
- ADR 017's mention of Node 22 is historical; this ADR supersedes it on the runtime version.
- The next bump is due when Node 28 reaches Active LTS (October 2028).
